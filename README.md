# 🧠 PsycedelicAI Wiki

Welcome to the documentation hub for **PsycedelicAI**.

This repository contains documentation, concepts, definitions, project explanations, working methods, architectural ideas and background material connected to the wider PsycedelicAI ecosystem.

The purpose of this Wiki is to make the work easier to understand, navigate and develop over time.

It brings together ideas that may otherwise be spread across:

- GitHub repositories
- AI conversations
- project notes
- prompts
- experiments
- meeting discussions
- technical documents
- personal working material

This Wiki is intended to function as a shared knowledge base and orientation system for the work.

---

# 🌐 What is PsycedelicAI?

PsycedelicAI is a human-AI collaboration and working system developed through the ongoing interaction between **Psycedelic** and AI.

Psycedelic represents the human perspective:

- lived experience
- purpose
- intuition
- values
- creativity
- emotion
- judgment
- personal meaning
- responsibility

AI contributes another perspective:

- analysis
- memory support
- research
- structure
- pattern recognition
- documentation
- synthesis
- comparison
- connections across time

Together, the work explores how human ideas and AI capabilities can be connected into useful tools, methods, systems and creative projects.

PsycedelicAI is not intended to replace human judgment.

It is intended to strengthen human understanding, creativity, autonomy and ability to act.

## 🔄 AI Continuity Architecture

Documentation about preserving context across conversations, models, tools, projects and time.

The central problem is that information can become fragmented between:

- different AI systems
- different conversations
- different documents
- different projects
- different people
- different stages of development

AI Continuity Architecture explores how to preserve and reconnect:

- decisions
- terminology
- project history
- working context
- human intent

# 🧩 Documentation principles

The documentation aims to distinguish between:

- confirmed information
- human decisions
- AI-generated analysis
- proposals
- assumptions
- open questions
- historical material
- current project status

This distinction matters.

An AI-generated suggestion is not automatically a human decision.

A concept is not automatically an implementation.

An experiment is not automatically a finished system.

The documentation should preserve those differences whenever they are relevant.
