# 🌐 What is PsycedelicAI?

PsycedelicAI is a human-AI collaboration and working system developed through
the ongoing interaction between **Psycedelic** and AI.

Psycedelic represents the human perspective:

- lived experience
- purpose
- intuition
- values
- creativity
- emotion
- judgment
- personal meaning
- responsibility

AI contributes another perspective:

- analysis
- memory support
- research
- structure
- pattern recognition
- documentation
- synthesis
- comparison
- connections across time

Together, the work explores how human ideas and AI capabilities can be
connected into useful tools, methods, systems and creative projects.

PsycedelicAI is not intended to replace human judgment.

It is intended to strengthen human understanding, creativity, autonomy and ability
to act.

# 🗂️ How the Repositories Relate to Each Other

The public repositories have different roles within the wider PsycedelicAI
ecosystem.

They should not automatically be treated as one single implemented system.

Some repositories document methods.

Some describe larger system concepts.

Some preserve experiments and development history.

Some provide orientation and documentation.

```text
Psycedelic
    ↓
Human experience, ideas and intent
    ↓
PsycedelicAI collaboration
    ↓
Prompts, conversations and experiments
    ↓
Documentation and structured concepts
    ↓
Reusable methods and system concepts
    ↓
Public repositories and future projects
```


# 🧩 Documentation Principles

The documentation aims to distinguish between:

- confirmed information
- human decisions
- AI-generated analysis
- proposals
- assumptions
- open questions
- historical material
- current project status

This distinction matters.

An AI-generated suggestion is not automatically a human decision.

A concept is not automatically an implementation.

An experiment is not automatically a finished system.

The documentation should preserve those differences whenever they are relevant.

---

## Human Authority

Psycedelic remains responsible for:

- purpose
- meaning
- values
- priorities
- final decisions
- external commitments
- publication
- project direction

AI may assist with:

- research
- analysis
- structure
- comparison
- drafting
- documentation
- pattern recognition
- continuity support

AI output should be reviewed before it is treated as a final decision or
published statement.

---

## Evidence and Interpretation

The documentation should distinguish between:

```text
Fact
    Directly supported by an available source

Interpretation
    An analysis or conclusion based on available material

Proposal
    A suggested future direction

Assumption
    Information being used without complete confirmation

Uncertainty
    Information that remains incomplete, disputed or unresolved

Implementation
    Something documented as actually built or demonstrated
```

The public work should avoid presenting an interpretation as an independently
verified fact.
